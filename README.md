# 墨锭试磨室

运行：

```bash
npm start
```

访问`http://localhost:3037`。数据保存在`data/ink-stick-testing.json`（可用`DB_PATH`、`PORT`环境变量覆盖）。

## 功能

- **墨锭管理**：建档、多次试磨记录、评分统计、状态流转（待试磨/已试磨/重点观察）。
- **仪器校准与量值溯源**（仪器校准标签页）：
  - 维护仪器（测量参数、量程、校准周期）与标准器；标准器必须逐级追溯到上级基准，否则拒绝登记。
  - 录入校准/复校结果：示值误差（修正值=-误差）、校准不确定度、所用标准器、有效期（默认按周期推算）。
  - 各级不确定度按方和根合成：仪器总不确定度 = √(校准U² + 溯源链各级的U²)，中间值不修约。
  - 仪器**超差、过期、停用或溯源链断裂**（上级证书过期/缺失/未接基准）时不可用于试磨结论，试磨提交被拦截并说明原因。
  - 校准超差后，上次校准以来的试磨记录自动标为**待复核**并生成影响记录；复校合格后可**复核重算**：按原始读数+新修正值重算评分，保留前后版本（`versions`），影响记录闭环。
- **一致性保障**：空库初始化单例执行（并发首访只初始化一次，失败可重试不破坏数据）；校准、停用、复校、复核接口支持`Idempotency-Key`幂等（重复/并发只成功一次，返回首次结果）；全部写操作串行排队；写盘采用唯一临时文件+rename原子替换，写失败不留半条仪器、证书或影响记录。
- **状态计算规则**：仪器当前状态按校准日期最新的证书及其有效性判定（补录旧日期校准不会覆盖当前状态）；校准日期晚于当天直接拒绝，库中未来日期的证书不作为当前有效证据；有效期按校准日期+周期推算，月末加月溢出时回落到目标月最后一天；整条溯源链的测量参数必须一致，跨物理量的链判为断裂；超差影响窗口按校准日期定位为`[上一次校准, 下一次校准)`；整锭状态始终由全部当前有效试磨记录中最新一条的评分决定。

```bash
npm test
```

独立临时库起服务跑全流程断言（并发初始化、溯源强制、失准→待复核→复校→复核重算、幂等与并发、过期/断链、补录校准、写盘原子性），不触碰正式数据。

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/instruments | 仪器列表（含有效期、剩余天数、合成不确定度、溯源链、受影响记录） |
| POST | /api/instruments | 登记仪器 |
| POST | /api/instruments/:id/calibrations | 录入校准/复校（`kind`区分），超差自动标记待复核 |
| POST | /api/instruments/:id/deactivate · /activate | 停用/启用（自然幂等） |
| POST | /api/instruments/:id/review | 复核：复校合格后按原值重算受影响记录 |
| GET/POST | /api/standards | 标准器列表（含溯源链状态）/ 登记标准器 |
| GET | /api/impacts | 影响记录（失准事件与受影响试磨记录） |
| POST | /api/items/:id/action | 试磨记录（可关联`instrumentId`，评分按修正值校正） |
